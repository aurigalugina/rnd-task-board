# Blocker Logs

Directory for recording active/past blockers encountered during development.

- Filename: `{topic}-YYYYMMDD-blocker.md`
- Sections: `## Deskripsi`, `## Dampak`, `## Opsi Solusi`, `## Yang Dibutuhkan`
- When resolved, append a `## Resolution` section describing how/when it was resolved.

See `CLAUDE.md` → "Blocker Log" for the full policy.
